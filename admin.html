데이터 관리

내보내기 준비됨
임시 저장은 지금 쓰는 브라우저에만 남습니다. 모든 방문자에게 반영하려면 data.json을 내보내고 GitHub 저장소의 data.json을 새 파일로 교체해야 합니다.

전체 디자인

사이트 전체 색상, 카드 모양, Hero 분위기, 여백감을 바꿉니다.

방문자 페이지 전체 폰트에 적용됩니다. 내보낸 data.json을 GitHub에 교체해야 실제 사이트에도 반영됩니다.
