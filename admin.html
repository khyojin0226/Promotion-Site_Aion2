길드 홍보 data.json 관리

여기서 내용을 수정한 뒤 반드시 data.json 내보내기를 눌러 GitHub 저장소의 data.json과 교체하세요.

index.html 열기
1단계: 내용 수정
2단계: data.json 내보내기
3단계: GitHub 저장소의 data.json 교체
4단계: GitHub Pages에서 반영 확인

데이터 관리

내보내기 준비됨
임시 저장은 지금 쓰는 브라우저에만 남습니다. 모든 방문자에게 반영하려면 data.json을 내보내고 GitHub 저장소의 data.json을 새 파일로 교체해야 합니다.

전체 디자인

사이트 전체 색상, 카드 모양, 메인 화면 분위기, 여백감을 바꿉니다.

방문자 페이지 전체 폰트에 적용됩니다. 내보낸 data.json을 GitHub에 교체해야 실제 사이트에도 반영됩니다.

메인 타이틀 영역

비어 있거나 로딩에 실패하면 금빛 판타지 fallback 배경이 표시됩니다.

Intro 영역

첨부 이미지는 참고용입니다. 실제 이미지는 사용자가 준비해서 경로를 입력합니다.

인트로 이미지 미리보기

중앙 아티클 영역

본문은 한 줄이 bullet 하나입니다. 각 아티클의 배치는 아티클별 `아티클 배치`에서 따로 바꿀 수 있습니다.

갤러리 영역

사진은 assets 폴더에 넣고 `assets/gallery-1.png`처럼 경로를 입력하세요. GIF도 사용할 수 있습니다.

하단 안내 영역
